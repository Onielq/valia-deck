# Valia — Dubai Creek Harbour Project Study

This repository contains a five-page, browser-based presentation about Valia in Dubai Creek Harbour.

## Open the presentation

Open **[index.html](./index.html)**. It forwards to the original self-contained presentation file, [valia_deck_images_and_icons.html](./valia_deck_images_and_icons.html).

You can also open that HTML file directly in a modern browser. No Node.js install, package manager, build step, or server is required.

## Presentation structure

1. **Launch overview** — project facts, residence mix, launch prices and payment plan.
2. **The investment case** — unit-level value analysis and the two-bedroom ensuite feature.
3. **The districts** — Dubai Creek Harbour masterplan and surrounding districts.
4. **Comparables** — Valia's launch pricing against Dubai Creek Harbour and Downtown Dubai.
5. **Location and lifestyle** — Dubai Square and the nearby district context.

## Repository notes

- The original five-page presentation is preserved as a single HTML file.
- Its 29 presentation images are embedded in the HTML, so there is no separate image-assets folder to maintain.
- Typography loads from Google Fonts when the browser is online and falls back to system serif/sans-serif fonts when it is not.
- The deck uses a fixed 16:9 landscape page size. On narrow screens, view it in landscape or use horizontal scrolling.
- The source is a static reference deck. It is not the production Taiseel/Rwanda Land Intelligence application.
