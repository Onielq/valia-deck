# Valia - Dubai Creek Harbour

A five-page Valia launch presentation.

## Open the deck

Download [index.html](./index.html) and open it in a modern browser. The presentation images are embedded in the HTML, so it does not depend on a separate assets folder.

## Included pages

1. Launch overview
2. Unit mix, pricing and payment plan
3. Dubai Creek Harbour masterplan and districts
4. Comparable pricing and market opportunity
5. Dubai Square, location and lifestyle

The supplied Valia PDF was used as the visual source for the tower render, floor plan, masterplan and location imagery. The @yourhandle placeholder branding and watermark were removed.

Further property collections are intentionally not included yet.
