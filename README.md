# Bwiza Riverside Homes — Kigali Project Study

A five-page HTML project study for Bwiza Riverside Homes in Karama, Nyarugenge District, Kigali.

## Open the presentation

Open [index.html](./index.html) in a modern browser. The five pages form one continuous presentation. The project images are sourced from published project, government and news material; the location map loads from OpenStreetMap.

## Pages

1. Estate overview — developer, location, Phase I homes, completion and lowest published price
2. Unit mix and purchase terms — bedroom groups, floor areas, published prices, payment-guide terms and model-level value analysis
3. Development and community — Phase I, the five-phase programme and shared amenities
4. Market comparison — Rugarama Park Estate, Heza Estate and Masaka Views, with price-per-square-metre analysis for Bwiza's six published designs
5. Location and access — direct neighbouring landmarks, two mapped bus stops, site map and ADHI contact details

## Data notes

- ADHI's public property grid lists six house designs and asking prices. It does not disclose the number of Phase I units by bedroom group; the presentation marks those counts as not published.
- The public project record used here is RW-NYA-KAR-0001. It is an internal project reference, not a cadastral UPI. No verified UPI was available in the accessible record.
- Purchase-plan figures are taken from ADHI's December 2021 guide and are labelled historical. Buyers should confirm current terms with ADHI and the financing bank.
- Nearby bus-stop distances are straight-line estimates from the developer's published project pin, not walking-route distances.
- Comparable project prices refer to different unit sizes, types and delivery stages. They should not be read as like-for-like valuations.
